## 1. 设计原则

### 1.1 四条原则

| 原则 | 含义 | 反面案例 |
|---|---|---|
| **① 沟通是主角，问题状态是灵魂** | 界面上最重要的不是聊天气泡，而是**这条沟通围绕哪个问题、进展到哪一步** | 把问题状态藏进二级菜单 |
| **② 状态必须显眼，但克制** | "未读 / 已读未回复 / 已解决"要一眼可见，但**不做刺眼的告警式设计** | 满屏红色数字、弹窗催促 |
| **③ 克制的高级感** | 靠留白、层级、圆角与克制的色彩建立秩序，不靠渐变、阴影堆叠、动效炫技 | 玻璃拟态、霓虹渐变、粒子背景 |
| **④ 键盘优先** | 高频操作必须可纯键盘完成（搜索、切会话、发送、截图） | 关键操作只能鼠标点 |

### 1.2 与飞书的一致与差异

**照搬飞书的**（已被验证的高效形态）：
- 左侧窄导航栏 + 列表栏 + 内容区 三段式布局
- 消息气泡左右分栏、头像位置、时间分组
- 通讯录"组织树 + 人员详情"两栏结构
- 个人资料卡右上角进入、直属上级可点击跳转
- 顶部全局搜索（`⌘K`）

**必须区别于飞书的**（我们的差异化，也是产品核心）：
- **问题卡**：会话里的结构化卡片，承载状态与操作（飞书没有）
- **待办视图**：以"问题"而非"会话"为单位的列表（飞书没有）
- **已读留痕的呈现**：`未读 / 已读未回复` 徽标直接挂在问题卡和列表项上（飞书已读只到会话级）
- **数据看板**：知识缺口地图等（飞书没有）

> ⚠️ **一条设计红线**：所有涉及"个人状态/排名"的信息，**默认只呈现正向**（帮助榜、提问榜），不呈现"谁拖延/谁没回"。详见 PRD §7.3。

## 2. 设计系统（Design Tokens）

### 2.1 色彩

#### 品牌与语义色

```css
:root {
  /* 品牌主色 */
  --color-brand:          #3370FF;
  --color-brand-hover:    #245BDB;
  --color-brand-active:   #1A4CCC;
  --color-brand-light:    #E1EAFF;   /* 选中态背景 */
  --color-brand-lighter:  #F0F4FF;   /* 极浅底 */

  /* 功能语义色 */
  --color-success:        #34C724;
  --color-success-light:  #E8F8E6;
  --color-warning:        #FF8800;
  --color-warning-light:  #FFF3E5;
  --color-danger:         #F54A45;
  --color-danger-light:   #FEECEB;
  --color-info:           #3370FF;

  /* 特殊 */
  --color-unread:         #F54A45;   /* 未读红点 */
  --color-online:         #34C724;   /* 在线点 */
}
```

#### 中性色阶（飞书体系）

```css
:root {
  --color-text-1:  #1F2329;   /* 主要文字：标题、正文 */
  --color-text-2:  #646A73;   /* 次要文字：描述、时间 */
  --color-text-3:  #8F959E;   /* 辅助文字：占位、弱提示 */
  --color-text-4:  #BBBFC4;   /* 禁用态 */

  --color-border:  #DEE0E3;   /* 边框 */
  --color-divider: #E5E6EB;   /* 分割线 */

  --color-fill-1:  #F5F6F7;   /* 页面背景（列表栏、内容区底） */
  --color-fill-2:  #F0F1F2;   /* 次级填充（分组头、代码块） */
  --color-fill-3:  #EFF0F1;   /* 输入框内嵌底 */
  --color-bg-white: #FFFFFF;  /* 卡片、内容区 */

  --color-hover:      rgba(31, 35, 41, 0.05);   /* 列表 hover */
  --color-active:     rgba(31, 35, 41, 0.08);   /* 列表 active */
  --color-scrim:      rgba(0, 0, 0, 0.45);      /* 遮罩 */
}
```

> **深色模式**：本期**不做**（PRD 未列入范围）。但 token 化后可在后续通过 `<html data-theme="dark">` 覆盖变量实现，工程量可控。

#### 问题状态色映射（**规范唯一来源**）

| 状态 | 徽标文字 | 文字色 | 背景色 | 使用场景 |
|---|---|---|---|---|
| 未读 | `未读` | `#F54A45` | `#FEECEB` | 责任人尚未打开问题卡 |
| 已读未回复 | `已读，未回复` | `#FF8800` | `#FFF3E5` | 已读但超过 1 天无回复 |
| 已读已回复 | `已读 3 小时后回复` | `#646A73` | `#F0F1F2` | 正常在跟进 |
| 处理中 | `处理中` | `#3370FF` | `#E1EAFF` | 已有回复，未关闭 |
| 已解决 | `已解决` | `#34C724` | `#E8F8E6` | 提问方已确认 |
| 未解决 | `未解决` | `#8F959E` | `#F0F1F2` | 已关闭但未解决 |
| 已撤销 | `已撤销` | `#8F959E` | `#F0F1F2` | 提问方撤销 |

> ⚠️ **徽标不能只靠颜色区分**，必须同时有文字（可访问性要求，见 §9）。

**字号使用规则**：

| 场景 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 页面标题 | 20px | 500 | `--color-text-1` |
| 面板/模块标题 | 16px | 500 | `--color-text-1` |
| 列表项主标题（姓名/会话名） | 14px | 400 | `--color-text-1` |
| 列表项副标题（最后一条消息） | 13px | 400 | `--color-text-2` |
| 消息正文 | 14px | 400 | `--color-text-1` |
| 时间戳 | 12px | 400 | `--color-text-3` |
| 徽标 | 12px | 400 | 见状态映射 |
| 数据大数 | 24px | 600 | `--color-text-1` |

> **中文字重注意**：中文界面标题用 500（不要用 700，会显得笨重）。数字用 600 更清晰。

### 2.4 图标

- 统一使用线性图标（stroke 1.5px），尺寸 **16 / 20 / 24px** 三档。
- 图标必须与文字基线对齐；纯图标按钮必须有 `aria-label`。
- 推荐图标库：`@iconify/vue`（线性风格套装）或项目已有的图标系统。

## 3. 信息架构与全局布局

### 3.1 全局布局（三段式）

```
┌────────┬──────────────────────────┬─────────────────────────────────────────┐
│        │                          │                                         │
│  头像  │  ① 列表栏（可拖 240~400）│  ② 内容区                                │
│  ────  │                          │                                         │
│  消息  │  搜索框 / 筛选器          │  顶栏 56px：标题 + 操作                   │
│  通讯录│                          │  ─────────────────────────────────────   │
│  AI助手│  列表项                   │                                         │
│  待办  │  · 主标题 + 副标题        │  主体内容（滚动区）                       │
│  看板  │  · 时间 + 未读徽标        │                                         │
│        │                          │                                         │
│        │                          │  （聊天页有底部输入区）                    │
│  设置  │                          │                                         │
└────────┴──────────────────────────┴─────────────────────────────────────────┘
   68px              300px                          flex
```

**布局要点**：
- 导航栏固定 68px，**深色文字 + 浅灰底**（`--color-fill-1`），选中项：图标与文字变 `--color-brand`，背景加 `--color-brand-light` 圆角块。
- 列表栏与内容区背景：列表栏 `--color-fill-1`（浅灰），列表项卡片为白色圆角；内容区纯白。**用底色差而非分割线区分区域**（现代感的关键）。
- 列表栏与内容区之间**只有 1px 分割线**，不用阴影。
- 列表栏宽度可拖拽，状态持久化到 localStorage。

### 3.2 导航项与路由

| 顺序 | 导航项 | 图标语义 | 路由 | 说明 |
|---|---|---|---|---|
| — | 头像 | 用户头像 | `/settings` | 点击展开菜单（设置/退出） |
| 1 | 消息 | 气泡 | `/messages` | 会话列表 + 聊天 |
| 2 | 通讯录 | 联系人簿 | `/contacts` | 组织树 + 人员详情 |
| 3 | AI 助手 | 星芒 | `/assistant` | 找人 + 知识问答 |
| 4 | **待办** | 清单 | `/todo` | **我的问题（被问）**，带未读角标 |
| 5 | 看板 | 图表 | `/dashboard` | 报表 |
| — | 设置 | 齿轮 | `/settings` | 底部固定 |

**角标规则**：
- 「消息」显示**未读会话数**（不是未读消息数）
- 「待办」显示**未读问题数**（红色角标，超过 99 显示 `99+`）
- 其他项不显示角标

**快捷定位**：`⌘/Ctrl + 1~5` 依次切换到消息/通讯录/AI 助手/待办/看板。

### 3.3 常驻会话

「小管家」固定置于会话列表**置顶区**（在普通会话之上，浅色分组头"常驻"），头像使用品牌色系图标。
「AI 助手」是独立导航项，**不放在会话列表里**（避免与提问流混淆，见 PRD §3.2）。

**会话列表项规格**：

| 元素 | 规格 |
|---|---|
| 高度 | 64px（单行副标题）/ 72px（带徽标） |
| 内边距 | `--sp-2 --sp-3`，项之间 2px 间距 |
| 头像 | 36px 圆形；群聊用圆角方形（`--radius-md`）+ 成员拼图 |
| 主标题 | 14px / `--color-text-1`；有未读时 500 字重 |
| 副标题 | 13px / `--color-text-2`，单行省略号；自己发的加"我："前缀 |
| 时间 | 12px / `--color-text-3`，右上角；今天显示 `HH:mm`，昨天显示"昨天"，更早显示 `MM-DD` |
| 未读徽标 | 右上角，红底白字（`--color-not-unread`），胶囊形，最小宽 18px，`≥100` 显示 `99+` |
| **问题状态点** | 若该会话有**未读问题**，在副标题前加 6px 红点；有**已读未回复**问题加橙点 |
| 选中态 | 背景 `--color-brand-light`，左侧 3px 品牌色竖条 |
| Hover | 背景 `--color-hover` |
| 右键菜单 | 置顶 / 免打扰 / 标记已读 |

**列表分组**：`常驻` / `今天` / `昨天` / `更早`。分组标题 12px / `--color-text-3`，sticky 定位。

**聊天消息区规格**：

| 元素 | 规格 |
|---|---|
| 区块内边距 | 上下 `--sp-5`，左右 `--sp-6` |
| 头像 | 36px，距气泡 8px |
| 气泡最大宽 | 内容区 62%（约 560px 上限） |
| 气泡圆角 | `--radius-lg` 12px；贴近头像一侧的角用 4px（"尖角"效果） |
| 自己气泡 | 背景 `--color-brand`，文字白色 |
| 对方气泡 | 背景 `--color-bg-white` + 1px `--color-divider` 边框，文字 `--color-text-1` |
| 气泡间距 | 同人连续消息 4px，不同人 16px |
| 时间分组 | 超过 5 分钟间隔插入居中时间标签（12px / `--color-text-3`） |
| 发送状态 | 气泡右下角：`发送中`（转圈 12px）/ `失败`（红叹号，可点击重发） |
| 新消息提示 | 不在底部时，右下角浮出「↓ 3 条新消息」胶囊按钮 |
| 已读回执 | **仅在单聊**且为自己发送的最后一条消息下方显示「已读」（12px / `--color-text-3`） |

**输入区规格**：

| 元素 | 规格 |
|---|---|
| 容器 | 白色，顶部 1px 分割线，内边距 `--sp-3 --sp-4` |
| 输入框 | 无边框，最小高 40px，随内容增至 200px 后内部滚动 |
| 工具栏 | 左：`⊞ 更多` / `📎 附件` / `✂ 截图` / `@ 提及` / `😊 表情`；右：`发送` 主按钮 |
| 发送按钮 | 主色实心，圆角 `--radius-md`，高 32px；无内容时禁用（透明度 40%） |
| 拖拽区 | 拖文件到会话区时，整个消息区覆盖虚线边框 + 浅色蒙层"松开上传" |
| 粘贴 | 支持 `Ctrl+V` 粘贴图片/截图直接作为附件 |
| 提示 | 输入框上方显示"Enter 发送，Shift+Enter 换行"（首次使用 3 次后不再显示） |

## 5. 核心组件规格

### 5.1 按钮

| 类型 | 背景 | 文字 | 边框 | 场景 |
|---|---|---|---|---|
| Primary | `--color-brand` | 白色 | 无 | 主操作：发送、确认并联系、确认已解决 |
| Secondary | 白色 | `--color-text-1` | 1px `--color-border` | 次级：查看主页、取消 |
| Text | 透明 | `--color-brand` | 无 | 弱操作：查看详情、建议沉淀知识 |
| Danger | `--color-danger` | 白色 | 无 | 危险操作：撤销问题 |

**尺寸**：大 32px / 中 28px / 小 24px（高度）；圆角 `--radius-md`（6px）；内边距 水平 `--sp-4`。

**状态**：hover 加深 8% / active 加深 16% / disabled 透明度 40% + `cursor: not-allowed` / loading 显示 spinner 并保持宽度。

### 5.2 消息气泡

| 类型 | 呈现 |
|---|---|
| 文字 | 14px / `--lh-normal`；支持换行、URL 自动识别 |
| 图片 | 圆角 `--radius-lg`，最大 320×320，点击放大（lightbox） |
| 文件 | 卡片：文件图标 + 文件名 + 大小 + 下载按钮；宽 280px |
| 语音 | 气泡内波形 + 时长，宽按语音长度 120~280px |
| 视频 | 缩略图 + 播放按钮，最大 320×240 |
| 系统消息 | 居中、12px、`--color-text-3`、浅灰胶囊底 |
| 已撤回 | 居中、12px、`--color-text-3`、"xx 撤回了一条消息" |

**引用回复**：气泡上方显示 1px 竖线 + 被引用内容（13px / `--color-text-2`，单行省略）。

**@提及**：在气泡内高亮为品牌色，点击跳转个人主页。

## 8. 动效规范

### 8.1 基础参数

```css
:root {
  --duration-fast: 120ms;   /* hover、按钮态 */
  --duration-base: 200ms;   /* 面板切换、浮层 */
  --duration-slow: 320ms;   /* 抽屉、模态 */
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);      /* 进场 */
  --ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);    /* 位移 */
}
```

### 8.2 场景表

| 场景 | 效果 | 时长 |
|---|---|---|
| 按钮 / 列表项 hover | 背景色过渡 | 120ms |
| 导航项切换 | 背景块淡入 | 120ms |
| 会话切换 | 内容区淡入（不加位移） | 200ms |
| 消息新到达 | 淡入 + 上移 4px | 200ms |
| 浮层 / 下拉 | 淡入 + 上移 4px + 缩放 0.98→1 | 200ms |
| 抽屉（问题详情） | 从右滑入 480px | 320ms |
| Modal | 淡入 + 缩放 0.96→1 | 200ms |
| Toast | 从顶部滑入 | 200ms |
| 发送中 → 已发送 | 图标透明度过渡 | 120ms |

### 8.3 禁止项

- ❌ 视差、粒子、背景动画
- ❌ 超过 400ms 的动画
- ❌ 列表项交错（stagger）入场 —— 消息多时会拖慢感知
- ❌ 持续闪烁/呼吸效果（尤其不能用于提醒未读，会制造焦虑）
- ✅ 必须支持 `prefers-reduced-motion: reduce`（关闭所有非必要动效）

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 9. 可访问性

| 项 | 要求 |
|---|---|
| **对比度** | 正文文字与背景对比度 ≥ **4.5:1**；大字号（≥18px）≥ 3:1 |
| **状态不依赖颜色** | 徽标必须带文字；不只靠色块区分状态 |
| **键盘可达** | 所有交互元素可 Tab 到达并有可见焦点环 |
| **焦点环** | 2px `--color-brand`，偏移 2px；**禁止 `outline: none` 而无替代** |
| **图标按钮** | 必须有 `aria-label`（如 `aria-label="发送附件"`） |
| **动态区域** | 消息列表用 `aria-live="polite"`，避免读屏频繁打断 |
| **表单** | 输入框必须有关联 `<label>`（可用视觉隐藏） |
| **跳转链接** | 提供"跳到主要内容"的 Skip Link |
| **语义标签** | 使用 `nav` / `main` / `aside` / `article`，不用一堆 `div` |
| **字号可调** | 用户浏览器字号放大到 125% 时布局不破 |

| 要点 | 做法 |
|---|---|

### 12.1 飞书的四个视觉基因（必须先做到，再谈功能）

照着飞书做，不是抄它的图标，而是吃透这四个特征。上一版视觉稿之所以"不好看"，就是在这四条上跑偏了：

| 基因 | 飞书的做法 | 常见做错的方式 |
|---|---|---|
| **① 白底为主** | 内容区、消息区、卡片全白；只有左栏是浅灰 | ❌ 大面积灰底 + 白卡片"浮"在上面，显得脏且重 |
| **② 极轻分隔** | 一律 `0.5px` 实线，透明度 9%~14%；**几乎不用阴影** | ❌ 1px 深灰边框 + `box-shadow`，视觉噪点极多 |
| **③ 灰阶层次** | 四级灰（`#1F2329` / `#646A73` / `#8F959E` / `#BBBFC4`）严格分层，正文用一级灰不用纯黑 | ❌ 到处纯黑 + 到处加粗，失去层次 |
| **④ 大留白、小圆角** | 行高 1.6、块间距 16px 起；圆角 6~10px，窗口外层才 14px | ❌ 圆角 20px+ 的"气泡卡片风"、行距 1.3 的拥挤排版 |

### 12.2 实测布局尺寸（原型已验证）

```
┌── 68px ──┬──── 300px ────┬────── flex ──────┬── 320px ──┐
│ 导航栏    │  列表栏        │   主内容区        │  详情面板  │
│ 浅灰      │  近白          │   纯白            │  浅灰      │
│ rail      │  list         │   main           │  panel    │
```

### 12.3 关键还原点（逐条对照可直接验收）

1. **会话列表条目两行结构**：第一行「名称 + 时间（右对齐、`#BBBFC4`）」，第二行「预览文字 + 状态标签」。名称 14px/400，hover 与选中态变 500 —— 飞书的"选中加粗"就是这个细节。
2. **机器人头像用圆角方块（9px），人用圆形**。这一条几乎是飞书最容易被认出的身份标识，必须区分。
3. **文字消息无气泡**：他人消息 = 头像 + 12px 灰色昵称 + 14px 正文，**直接铺在白底上**；只有自己的消息用 `#D6E4FF` 浅蓝气泡靠右。
4. **卡片式消息用 0.5px 描边而非阴影**（问题卡、文件卡），卡片头 11px 内边距 + 底边线，卡片脚按钮区底色 `#FCFCFD`。
5. **系统消息居中、浅灰胶囊**（`rgba(31,35,41,.045)` 底 + `#8F959E` 字），用于"已立项""首次响应于…"。**不要做成聊天气泡**，它是事实陈述不是对话。
6. **输入区两段式**：上排工具栏（表情/图片/文件/截图/@/更多，图标 30px 热区），下排输入框 + 蓝色「发送」。占位文案沿用飞书式：「发送消息或按住 Fn 说话」。
7. **主导航只保留 6 项 + 更多**：消息 / 通讯录 / 待办 / AI 助手 / 看板 / 更多。飞书有十几个入口是因为业务多，我们堆多了反而找不到重点。

### 12.4 与飞书的 5 处**必须不同**（照抄会出问题）

| 差异点 | 飞书 | FpIM 必须 | 原因 |
|---|---|---|---|
| 会话列表分组 | 推荐 / 群组 / 联系人 | 推荐 / 群组 / 联系人 / **待办未闭环** | 「我欠着谁的问题」是这个产品的第一诉求，不能藏在筛选里 |
| 待办入口 | 无 | **独立导航项 + 红点数字** | 被问方每天要打开的不是"会话"而是"我欠的问题" |
| 消息列表的"处理中"标记 | 无 | 会话条目第二行带**状态标签** | 会话与问题绑定，列表即可看出闭环进度 |
| 详情面板 | 群成员/群设置 | **问题详情 + 处理过程时间线** | 过程留痕是核心资产，必须在主界面可查 |
| 状态徽标 | 仅色点/无 | **必须带文字**（"已读，未回复"） | 只靠颜色会被读成"系统给我亮红牌"；带文字才是中性事实陈述 |

### 12.5 原型里已落地的设计系统（写代码时直接取用）

原型 `../prototype/fpim-mockup.html` 的 `:root` 即为 §2 全部 token 的**可运行版本**，与本文档 §2.1 完全一致，包含：

- 品牌/语义色 12 个、中性色阶 4 级灰 + 3 档填充、悬停与选中透明度
- 状态徽标色（`处理中` 用蓝色 `#3370FF` / `#E1EAFF`，与 §2.1 状态色映射表一致；`已读未回复` 用 `#FF8800` / `#FFF3E5`）
- 圆角 `6 / 8 / 10 / 14`、边框统一 `0.5px`、零阴影（仅窗口级一处投影，模拟 macOS 窗口）

> **新增界面时的自检**：新页面里如果出现了 `box-shadow`、`1px` 边框、纯黑文字或 20px 以上圆角，基本可以判定偏离了飞书体系。
