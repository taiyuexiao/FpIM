# 野火 IM 调研

- 组织：https://github.com/wildfirechat
- 核心仓库：im-server ~8550★（2026-09-08 提交）、vue-chat ~226★（Vue3 Web 端）、vue-pc-chat ~159★（Electron）、organization-platform 7★（MIT）
- 活跃度：2025-2026 持续活跃，核心仓库本月均有提交，专职团队处理 issue
- 协议：**CC BY-ND 3.0（禁止演绎，非标准软件协议）**；官方口径社区版免费商用，但 README 强调"不要修改 IM 服务代码，修改后不再提供技术支持"

口径标注：**【社区】**= 社区版免费含 / **【专业】**= 需专业版 IM 服务（2.9 万/套）/ **【付费】**= 单独收费 / **【二开】**= 需自行开发（有官方示例）。

## 技术栈

Java + Netty，MQTT + Protobuf；存储默认 H2，生产切 **MySQL**（按月分表，不支持 PG；MongoDB 仅专业版）；最小部署 im-server + app-server 两个 JVM 进程。**硬性限制：社区版强制使用 80 端口**（反诈监管设计，政企可凭证明免费定制端口）。

## 详细功能清单

### 消息能力

- **内置消息类型【社区】**：文本(1)、语音(2)、图片(3)、位置(4)、文件(5)、视频(6)、动态表情(7)、链接(8)、**名片(10，用户/群/频道)**、组合消息(11，即合并转发，超 50KB 转媒体消息)、富通知(12)、文章(13)、**AI 流式输出三件套(14 生成中/15 完成/20 取消)**、提醒消息/小灰条(90)、群通知类、音视频信令类
- 自定义消息【社区】：类型号 >1000，payload 含 searchableContent/pushContent/extra/expireDuration（消息定时过期）
- @提醒【社区】（@部分人/@全体，独立 @消息回调）；引用回复【社区】
- 离线消息【社区】：每用户缓存最近 1000 条消息 ID，全部落库，按 messageUid 拉取
- 漫游/远程历史【社区，配置开关，默认关】
- 撤回【社区】：默认时限 120 秒可配（0=禁止，-1=不限）；群主可撤回任意成员消息、管理员可撤回普通成员消息；**Server API 撤回不受时限**
- 消息更新/服务端删除/清空用户消息/广播：**【专业】**
- **已送达/已读回执【专业】**：功能列表明确"社区版不支持"；按会话记最后送达/阅读时间点（非逐条）
- 消息搜索【社区】（客户端本地搜索）；收藏【社区】

### 会话能力

- 会话类型【社区】：单聊(0)、群聊(1)、聊天室(2)、频道(3，类公众号)、**密聊(5，端到端加密+阅后即焚)**；会话有 line 字段可按业务线隔离（适合"提问"场景独立成线）
- 置顶【社区】、会话免打扰【社区】、全局静音【社区】、未读数【社区】
- 草稿【社区】，但**草稿多端同步【专业】**；**已读状态多端同步【专业】**
- 会话自定义设置【社区】；机器人可写会话级设置（适合向会话同步业务状态）

### 群聊

- 群类型【社区】：Normal（类微信）、Free、Restricted（受限群，仅管理员操作）
- 人数上限【社区】：全局配置默认 2000，官方建议普通群 ≤500~1000（性能 O(N²)）；**超级群（万级~10 万）【专业】**，代价：不支持送达报告
- 群角色【社区】：普通/黑名单/群主；**白名单与管理员角色【专业】**；整群禁言【社区】，**指定成员禁言【专业】**
- 入群方式【社区】：邀请/扫码/面对面/加群验证；群公告【二开，有示例】；群昵称/群二维码/禁止成员私聊【社区】
- 群通知自定义【社区】：群操作可带 notify_message 定制内容

### 用户体系

- 资料字段【社区】：userId/name/displayName/mobile/portrait/email/address/company/gender/social/extra，可按字段隐藏防抓包
- **好友体系可关【社区】**：发消息不校验好友关系（免加好友单聊默认行为 ✅），也可禁止陌生人聊天并配白名单
- 黑名单【社区】（发送报错/静默丢弃两策略）
- 在线状态【专业/二开】：开箱在线状态/最后在线时间属专业版；可拿上下线回调自建
- 多端互踢【社区】：默认每平台一端、同平台互踢；可开任意多端；四平台消息多端同步
- 机器人【社区】：开源 robot_server、Robot API、Webhook 机器人、**机器人 MCP 服务（接 AI Agent）**

### Server API 与回调

- 调用方式【社区】：HTTP POST JSON，管理端口 18080，sha1 签名；官方 Java SDK，Python 直连即可
- 接口模块【社区】：用户（getToken/注册/封禁/禁言/在线用户列表/获取用户会话）、关系链、群组全套、消息（发送/组播/撤回/**导入历史消息**/获取会话已读时间戳/投递状态）、频道、聊天室、会议、敏感词
- 消息转发/回调【社区，配置开启】：**`message.forward.url` 全量或按类型转发消息 → 提问消息落库统计直接可用**；另有 @/撤回/敏感消息/上下线/用户/关系/群/会议全生命周期回调。注意回调单线程推送，接收方须同内网 + 异步快速返回
- 内容审核【社区】：`sensitive.remote_server_url` 接独立审核服务，200 放行（可替换内容）、403 拦截

### 安全合规

- 传输 AES128 加密（可选 AES256）【社区】；客户端本地库 SqlCipher【社区】；服务端消息可加密落库（开启不可回退）【社区】；密聊端到端加密【社区】
- 敏感词【社区】：内置词库 + API 增删，命中策略可配（失败/丢弃/替换***/放行），命中记录落表并可回调通知管理员；另有免费开源"防诈骗服务"
- 反诈硬性限制：社区版强制 80 端口；收费产品仅售境内法人；SDK/专业版绑定域名或 IP 不可变更

### 管理后台

**无免费管理后台**。官方管理后台【付费源码 3 万】：统计首页、用户管理（含查看/代发消息）、敏感词管理、群组管理、消息管理（广播仅专业版）、机器人/频道管理。免费替代：频道管理后台免费；其余建议基于 Server API 自建。

### 消息保存策略

- MySQL 按月分表共 36 张，**默认保留 35 个月（约 3 年）自动清理【社区】**，可缩短
- 归档服务 archive-server【社区，开源免费，Java，2026-03 仍更新】
- 媒体文件：内置存储/七牛【社区】；阿里云/腾讯云/S3/MinIO【专业】
- 直接改库不生效（有缓存），写必须走 Server API；**读库做统计不受影响**

### 音视频

- 免费版【社区，SDK 闭源免费商用】：1v1 音视频、多人音频 9 路、视频 4 路，Mesh/P2P，需自部署 coturn；Web 端音视频依赖付费 Web SDK
- 高级版【付费 5.9 万】：SFU、百人会议、录制，依赖专业版 IM
- 配套：会议纪要服务（免费开源，实时转写）；语音转文字（付费）

## 结论

**不推荐**——功能契合度高（免好友单聊、名片消息、消息转发回调、漫游都是现成的），但 PC/Web 付费墙（专业版 2.9 万 + Web SDK 1 万起）+ CC BY-ND 禁止演绎 + 已读回执/群管理员等专业版功能 + Java/MySQL 栈不匹配。208 人若只做单聊+小群且接受付费与锁定可谈，否则规避。
