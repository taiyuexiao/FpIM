## 一、FpIM 现状盘点（2026-10-05，逐域差距）

> 判级：✅ 已具备 ｜ 🟡 有基础不完整 ｜ ❌ 缺失。

### 1.1 消息通道与可靠性

| 能力 | 现状 | 判级 | 说明 |
|---|---|---|---|
| 消息幂等 | `clientMsgId` 全链路（WS/HTTP/桥接/工具）去重 | ✅ | 一期打下的底子，发布凭据也靠它 |
| 会话内顺序 | 服务端 seq 单调递增，客户端不依赖本地时钟 | ✅ | |
| 断线重连 | 指数退避重连 + `resyncAll()` 按 lastSeq 增量补齐 | 🟡 | 有增量拉取，但无心跳保活、无"半开连接"检测；重连风暴无退避上限 |
| HTTP 兜底 | WS 不可用走 REST 发送，同幂等 | ✅ | |
| 发送状态机 | 乐观消息 pending → ack 替换；失败保留正文 | 🟡 | 缺「失败可重发」「状态未知（delivery_unknown）」两态 |
| 投递语义 | 无显式 outbox；桥接同步调用 | ❌ | Agent 桥在 `send_message` 内同步执行（DeepSeek 最长 30s），拖慢发送主链——**已知的头号性能债** |
| 存储模型 | 单库单表 `im.messages`，`beforeSeq` 分页 | 🟡 | 200 人可用；无分区/归档/冷热分层规划 |
| 多端一致性 | 同账号多端都能收发 | ❌ | 无多端同时在线管理、无互踢/共存策略、消息状态跨端不同步 |
| 离线策略 | 离线消息靠增量拉取，永久保存 | 🟡 | 无离线推送通道（人不在 Web 前就丢通知）、无拉取窗口上限 |

### 1.2 安全

| 能力 | 现状 | 判级 | 说明 |
|---|---|---|---|
| 认证 | JWT（HS256），过期时间存在 | 🟡 | 无刷新/轮换机制、无登出失效（token 天然有效到期）、改密不吊销已发 token |
| WS 鉴权 | query 参数传 token | ❌ | token 进 URL → 会进代理/访问日志；应改首帧鉴权或短时 ticket |
| 越权防护 | 会话/消息/文件均有成员校验（`is_member`） | 🟡 | 有基础但未系统化（缺 IDOR 清单与回归测试）；外部 IM 回调仅静态 API key |
| XSS | 消息渲染以文本插值为主 | 🟡 | `v-html` 使用点（rail 图标、外链渲染）需专项审计；链接未做协议白名单 |
| 文件上传 | 类型提示 + 大小上限，内容寻址存储 | 🟡 | 无病毒扫描、无 MIME 嗅探校验、无图片重编码 |
| 传输加密 | 明文 HTTP（内网 127.0.0.1） | ❌ | 上线必须 TLS；内网是否 mTLS 待定 |
| 静态加密 | 无 | ❌ | PG/文件均明文落盘 |
| E2E 加密 | 无（服务端可读） | 🟡 | 银行内网+审计需求下服务端可读是合理取舍，但须**写进安全设计文档**而不是默认 |
| 审计 | `audit_logs` 已接线，管理员操作留痕 | 🟡 | 缺消息级敏感操作审计、日志防篡改 |
| Agent 安全 | 工具调用经确认、披露检查（授权群才代答） | 🟡 | 提示注入未防护（消息内容进 prompt）、DeepSeek key 单钥无轮换、companion 令牌长期有效 |

### 1.3 隔离与扩展

| 能力 | 现状 | 判级 | 说明 |
|---|---|---|---|
| 租户模型 | 单企业单库 | ✅（现状够用） | 若做多企业需 tenant_id 贯穿（库里已有先例字段要查） |
| 组织隔离 | 通讯录全员可见、搜索全员 | 🟡 | 银行部门敏感（总行/部门层级），可见性策略待产品定义 |
| WS 水平扩展 | 进程内 dict hub | ❌ | 单进程持有全部连接——重启掉线、无法多实例 |
| DB 扩展 | 单库直连、无连接池配置 | 🟡 | PgBouncer/读写分离未规划 |
| 缓存 | 无（全员列表每次拉 500 人） | 🟡 | 会话列表/未读/在线状态均直查 DB |
| 异步化 | Agent 桥同步 | ❌ | 同投递语义条目；长任务无队列 |

### 1.4 可观测与运维

| 能力 | 现状 | 判级 |
|---|---|---|
| 指标 | 仅 uvicorn 访问日志 | ❌ 缺在线连接数/端到端延迟/投递成功率/Agent 调用成功率 |
| 告警 | 无 | ❌ |
| 备份恢复 | 无定时备份（PROJECT.md 已挂"要资源"） | ❌ 数据库是唯一事实源，**最高优先级** |
| 限流降级 | 无限流；AI 挂了 IM 活着（降级启发式已做） | 🟡 |
| 灰度 | 无 | ❌ |
