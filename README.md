# FpIM —— 首问责任平台的 IM 化重构

> 把「找到人」延长到「**解决问题并留下证据**」。
> 原平台在“AI 找到责任人”之后就断了——沟通靠邮件往来，过程丢失。本项目把这段换成自研 IM（对齐飞书 7.x 交互），让处理全程留痕、可统计、可进人才选拔；并在其上引入 **DeepSeek 驱动的企业 IM Agent**（群内代答 / 私聊代理 / 工具调用）。

---

## 一、这是什么

原平台（`findperson`/首问责任平台）已经能做：自然语言提问 → AI 找人 / 找知识 → 指派责任人 → 跟进问题。
**本项目的重构点：把沟通渠道从邮件换成 IM，并让沟通行为自动沉淀成证据。**

- 不是新建问题闭环——`issues` / `issue_events` / 知识沉淀这套**本来就在跑**，本项目是**换渠道 + 补留痕**。
- 差异化不在聊天本身，而在聊天之外：**问题状态机、留痕、统计、画像、Agent**。没有采用开源 IM，而是自研内核——因为**消息必须与问题同库同事务**，否则报表数字和聊天记录必然对不上。

## 二、功能总览

### IM 会话（对齐飞书 7.x）

| 域 | 能力 |
|---|---|
| 会话 | 单聊（免加好友、同对人复用会话）、群聊（上限 100 人）、通讯录独立菜单（总行/部门多级树 + 拼音搜索）、飞书风极左导航栏 |
| 消息 | 文本（@提及高亮）、图片（点击放大查看器）、文件（拖拽发送/粘贴截图）、人员名片、**处理模板卡**、合并转发卡（点击回放）、问题卡、系统消息、小管家通知 |
| 消息操作 | 悬浮 icon 操作条（点赞/表情/回复/转发/更多）、**引用回复**、**撤回（2 分钟）**、**编辑（24h/20 次/已编辑标记）**、**单条转发 + 多选合并/逐条转发**、复制、删除（仅自己可见）、置顶消息 |
| 表情 | 表情回应（14 常用 + 聚合 + 再点撤回 + WS 多端同步）、表情面板（58 emoji 插入） |
| 会话管理 | 置顶/免打扰（右键菜单 + 设置菜单）、清空聊天记录（仅清视图，**留痕数据保留**）、会话备注、标为未读、查找聊天记录 |
| 群管理 | 改名/群公告（系统消息留痕）、拉人/踢人/退群、**转让群主**、**发言权限**（仅群主/全员）、成员列表含 Agent 卡 |
| 已读体系 | 已读游标 + 未读角标、单聊「已读/未读」、群聊「N 人已读」→ 已读/未读名单、问题级首次已读留痕（不可覆盖） |
| 搜索 | 会话内搜索（正文/文件名）、**全局搜索**（联系人/跨会话消息/会话三段式，点击跳转定位）、未读分隔线 |
| 输入 | 多行/草稿保留/@ 提及面板/快捷短语/Enter 发送（IME 安全） |

### 问题闭环（产品差异化内核）

`立项 → 问题卡挂接会话 → 已读/首响自动留痕 → 转办链 → 提问方确认解决 → 沉淀候选`

- **待办视图**：待我处理 / 我提出的（已读未读、已回复未回复两个留痕态）；
- **解决模板**：问题解决后一键沉淀为「问题 + 处理套路 + 责任人」模板，入**个人库/公共库**，可作卡片消息发给任何人（人工或 Agent 自动发送），并**进入问答检索范围**（搜问题时带出模板 + 责任人）；
- **评价**：解决后邀评（评分/标签/评语，仅提问方），进画像与帮助榜口径。

### Agent 能力（二期，DeepSeek 驱动）

| 能力 | 说明 |
|---|---|
| 全会话常驻 | 任何群/单聊都有「群聊 Agent」：成员列表可见、@ 候选首位、输入框 🤖 一键召唤（“我在，有何吩咐”） |
| 群内代答 | @知识库主人 / @Agent 命中知识库 → 依据材料作答并**注明出处**、说明缺口；未命中 → 实质交接并提醒本人（不装死、不说废话） |
| 知识库绑定 | 用户预提供知识（Agent 面板 📚 管理），**授权到群 = 披露边界**（能读≠能分享） |
| 私聊代理 | 三模式 **关闭 / 仅起草 / 自动处理**：未读期间（5s 窗口，已读即停）Agent 依据本人知识库自主代答，消息带「Agent 代处理」标识；覆盖不了就交接；**不做“请稍后”式废话回复** |
| 工具调用 | 「把名为 xx 的文件发给对方」→ 搜索（本地伴随程序优先，回退平台文件库）→ 同名消歧 → 发送 → **回消息凭据**；`scripts/local_companion.py` 授权目录运行，只搜不发 shell |
| 交互面板 | 会话右栏「问题详情 / AI 助手」双 tab，带当前会话上下文，动作以草稿卡呈现（写动作必经确认） |
| 治理 | 多 Agent 防抢答（归属幂等）、动作确认执行器、外部 IM HTTP 接入（API Key） |

### 报表与看板

帮助榜（含平均评分）/ 知识缺口地图 / **科室维度统计**（被问次数、解决件数与占比、回复时长 P50/均值）/ 个人数据画像 / 意见反馈。
设计红线：只公开正向榜、不做点名排行（详见 PRD）。

## 三、生产加固（上线闸门）

> 完整方案见 [docs/04-生产加固技术方案.md](docs/04-生产加固技术方案.md)（P0/P1 共 11 项已全部实施并实测；P2 触发条件驱动）。

| 域 | 已落地 |
|---|---|
| 数据安全 | 每日备份 + **恢复演练脚本**（`scripts/backup-db.sh` / `restore-drill.sh`，实测 16M 备份恢复出全部表） |
| 主链可靠 | **Agent 桥异步化**（发送主链从同步 30s 债降到 ~48ms）、发送状态机（发送中/成功/失败/状态待核实 + 幂等重发）、WS 心跳（30s ping / 75s 清理半开连接） |
| 安全 | WS 一次性 ticket 鉴权（JWT 不进 URL 日志）、**token_version 会话吊销**（改密/登出全端立即失效）+ refresh 静默续期、限流（登录爆破锁定/发消息/上传）、上传魔数嗅探 + 危险类型拒绝、文件下载 commonpath 防穿越 + 强制附件、**IDOR 越权回归 13 用例**、Agent 提示注入围栏 + companion 指令 60s 时效 |
| 可观测 | `/metrics` 最小指标集（WS 连接数/发送延迟直方图/消息计数/Agent 调用成功率） |

P2 规划（触发条件驱动）：hub 水平扩展（Redis pub/sub，广播出口已收敛为单函数）、消息表按月分区、静态加密、E2E 评估（结论先行：主链不上，审计优先）。

## 四、快速开始

```bash
./start-dev.sh        # 拉起后端(8002)+前端(5175)，数据库不在先拉 Docker
./start-dev.sh stop   # 停掉
```

打开 **http://127.0.0.1:5175**，账号 `P0004~P0007`，密码见 `findperson/backend/.env` 的 `SEED_PASSWORD`。
日志在 `.workbuddy/logs/`；备份：`scripts/backup-db.sh`（恢复演练 `restore-drill.sh`）。

自测：

```bash
cd findperson/backend
venv/bin/python scripts/fpim_smoke_http.py --reset   # 58 项（--reset 清空 im 数据）
venv/bin/python scripts/fpim_smoke_ws.py             # 13 项
venv/bin/python -m pytest tests/ -q                  # 58 项（含 IDOR 越权回归 13 用例）
```

## 五、技术栈与架构

| 层 | 技术 |
|---|---|
| 前端 | Vue 3.5 + Vite 6 + Pinia + Element Plus（飞书风设计令牌 `--im-*`） |
| 后端 | FastAPI + SQLAlchemy 2 + PostgreSQL（`im` schema 与业务同库同事务）；`uvicorn[standard]` WebSocket 网关 |
| Agent | DeepSeek（所有 Agent 能力默认大脑，失败降级启发式）+ 可替换 Brain 协议 + 动作确认执行器 + 本地伴随程序（可选） |
| 安全 | JWT + token_version、WS ticket、限流、魔数嗅探、审计日志 |

两条不可协商的架构铁律：**① 消息与问题同库同事务**（报表/画像全是 SQL 聚合）；**② Agent 只读推理，写动作必经确认**（由 backend 执行）。

## 七、凭据约定（重要）

**仓库内不含任何明文凭据。** 所有口令、密钥从 `.env` 注入（已 gitignore），`.env.example` 只放 `CHANGE_ME` 占位符：

| 变量 | 用途 |
|---|---|
| `DATABASE_URL` / `PGPASSWORD` | 数据库连接 |
| `JWT_SECRET` | 登录令牌签名（`openssl rand -hex 32`） |
| `SEED_PASSWORD` | 种子账号口令 |
| `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` | 所有 Agent 能力的默认大脑 |
| `GROUP_AGENT_API_KEY` | 外部 IM 接入 Agent 网关 |
| `METRICS_TOKEN` | `/metrics` 抓取令牌（不配则仅管理员） |
