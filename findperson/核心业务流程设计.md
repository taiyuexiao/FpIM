# 首问责任平台核心业务流程设计

本文档描述用户实际使用平台时的页面流转与操作链路，重点说明用户从哪里进入、输入或点击什么、系统如何反馈，以及下一步可以去哪里。

## 一、用户提问并找到负责人的链路

**页面流转：** 登录首页（智能问答） -> 输入问题 -> 查看推荐结果 -> 查看人员详情/人员主页 -> 联系负责人或继续提问。

1. 用户登录平台后，默认进入“智能问答”首页。
2. 用户在输入框中输入问题，例如“报销系统权限申请应该找谁？”。
3. 用户点击发送，页面展示系统回复和人员推荐卡片。
4. 用户在推荐卡片中查看首推人员、可协助人员、部门、岗位、负责领域及推荐理由。
5. 用户点击人员卡片，在当前页面右侧打开人员详情；如需了解更多，可点击“查看主页”进入该人员主页。
6. 用户在人员主页查看联系方式、负责领域、自画像、他画像及已发布内容，并通过联系方式联系负责人。
7. 若推荐不符合预期，用户返回问答页补充问题条件，或点击“没帮助”提交反馈后重新提问。

## 二、通过问答修改个人资料的链路

**页面流转：** 智能问答首页 -> 输入资料修改需求 -> 资料维护确认卡 -> 确认更新/手动编辑 -> 个人主页更新完成。

1. 用户在智能问答首页输入修改需求，例如“把我的联系电话改为 138xxxx8888”“我现在负责采购系统权限管理”。
2. 系统识别用户想修改个人资料，并在对话区生成资料维护确认卡。
3. 用户在确认卡中查看系统识别出的修改内容，例如联系方式、岗位、负责领域或自画像。
4. 信息无误时，用户点击“确认更新主页”，系统提示“个人资料已更新”，确认卡变为已完成状态。
5. 信息需要补充或修改时，用户点击“手动编辑”，跳转至个人中心的编辑页。
6. 用户在编辑页完善资料并点击“保存主页”，页面返回个人主页展示状态。
7. 用户再次进入名片库、人员主页或智能问答时，可看到最新的个人资料；后续人员推荐也会使用新资料。

## 三、通过问答发布内容的链路

**页面流转：** 智能问答首页 -> 输入发布需求 -> 内容草稿卡 -> 确认发布/手动补充 -> 内容详情或我的发布。

1. 用户在智能问答首页输入发布需求，例如“我要发布一篇采购系统权限申请流程说明”。
2. 系统根据用户输入生成内容草稿卡，展示标题、关联领域、摘要和正文概要。
3. 用户预览草稿内容。
4. 草稿内容满足要求时，用户点击“确认发布”，系统提示发布成功，草稿卡更新为“已发布”。
5. 用户点击“查看内容”，进入内容详情页查看已发布内容；内容同时出现在个人中心的“我的发布”和个人主页中。
6. 草稿内容还需完善时，用户点击“手动补充”，跳转到内容发布页，系统自动带入草稿内容。
7. 用户补全标题、关联领域、摘要和正文后点击“发布”，页面提示成功，用户可返回来源页面或继续查看内容。

## 四、为他人补充画像的链路

**页面流转：** 智能问答首页/个人中心 -> 选择“为他人画像” -> 填写同事与事项 -> 确认保存 -> 查看他画像结果。

1. 用户可以在智能问答首页输入“我要补充张三的画像”，也可以进入个人中心后点击“为他人画像”。
2. 页面打开“为他人画像”表单，用户选择同事、日期和协作事项。
3. 用户从候选事项中选择标签；若没有合适事项，选择“其他”并输入自定义事项。
4. 用户确认信息无误后，点击“保存评价”或“确认保存评价”。
5. 系统提示保存成功，用户可进入该同事的人员主页查看更新后的“他画像”。
6. 用户回到个人中心，可在“我添加的事项”中查看自己提交过的记录，并可继续补充、修改或删除本人记录。
7. 该事项会作为对该同事实际协作能力的补充，并在用户后续提问找负责人时参与推荐。

## 五、从名片库筛选并查看人员主页的链路

**页面流转：** 左侧导航“名片库” -> 搜索/部门筛选 -> 人员卡片列表 -> 人员主页 -> 查看内容详情或返回名片库。

1. 用户点击左侧导航中的“名片库”。
2. 用户在搜索框输入姓名、岗位、职责或负责领域关键词，例如“采购”“权限管理”。
3. 用户按需要选择一级、二级、三级部门，部门下拉框会随上一级选择联动。
4. 页面刷新人员卡片列表，用户浏览姓名、部门、岗位、负责领域和自画像摘要。
5. 用户点击目标人员卡片，进入该人员的人员主页。
6. 用户在人员主页查看完整职责信息、自画像、他画像和个人发布内容；点击某篇内容可进入内容详情。
7. 用户点击返回，回到保留搜索条件和部门筛选条件的名片库列表，继续查看其他人员。

## 六、本人内容发布、编辑、置顶、删除的链路

**新增内容页面流转：** 个人中心 -> 点击“发布” -> 内容发布页 -> 填写并发布 -> 我的发布/内容详情。

1. 用户进入个人中心，点击“发布”。
2. 页面进入内容发布页，发布人自动显示为当前用户。
3. 用户填写标题、关联领域、内容摘要和正文，点击“发布”。
4. 系统提示发布成功，内容出现在个人中心“我的发布”列表和个人主页中。

**编辑、置顶、删除页面流转：** 个人中心 -> 我的发布 -> 点击管理操作 -> 完成后刷新列表。

1. 用户在个人中心找到“我的发布”列表。
2. 用户点击某条本人内容的“编辑”，进入编辑页修改内容并点击保存；返回列表后展示最新内容。
3. 用户点击“置顶”，该内容出现置顶标识并排列在本人内容列表前部；再次点击可取消置顶。
4. 用户点击“删除”，系统弹出二次确认提示。
5. 用户确认删除后，系统提示删除成功，该内容从“我的发布”、个人主页和公开查看入口中消失。

## 七、后台查看运营数据的链路

**页面流转：** 左侧导航“后台管理” -> 查看核心指标 -> 查看推荐榜单与活跃趋势 -> 切换筛选条件 -> 观察运营结果。

1. 管理员点击左侧导航中的“后台管理”。
2. 页面展示核心指标，包括参与人员数量、发布内容数量、覆盖领域数和本周推荐量。
3. 管理员向下查看推荐榜单，了解哪些人员被推荐较多，以及其关联领域。
4. 管理员查看活跃趋势，了解近期提问、资料维护、他人画像补充和内容发布等使用情况。
5. 管理员按需要切换时间范围或业务领域，页面同步刷新指标、榜单和趋势数据。
6. 管理员根据数据发现信息缺失或领域覆盖不足的情况，再通知相关人员补充个人资料、画像或内容；补充后的数据将在下一次统计中体现。

## 八、用户链路总览

用户以智能问答首页为主要入口：提问后可以直接找到负责人，也可以把“修改资料”“发布内容”“补充他人画像”等自然语言需求转为具体操作。名片库提供主动找人的路径，个人中心承接本人资料和内容管理，后台管理则面向管理员观察平台运营情况。所有完成的资料、画像和内容都会反映到人员主页和后续负责人推荐中，形成持续使用的闭环。
